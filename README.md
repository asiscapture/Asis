# Vera website

Lifestyle camera hire site for **Vera** — *capture life as is*. Brisbane hire.

## Open locally

Open `index.html` in your browser, or from this folder run:

```bash
npx --yes serve .
```

## SEO / domain

Canonical URLs, Open Graph and `sitemap.xml` currently use **`https://asiscapture.com.au`**.

When your real Vera domain is ready, find-and-replace that URL in:

- `index.html`, landing pages, `robots.txt`, `sitemap.xml`

Then submit the sitemap in [Google Search Console](https://search.google.com/search-console).

Also claim / update your **Google Business Profile** for Brisbane.

## Connect your inbox

Enquiries use [Web3Forms](https://web3forms.com) → `asis.capture@gmail.com`.

1. Create an access key with that email.
2. In `index.html`, replace `YOUR_WEB3FORMS_ACCESS_KEY` with your key.
